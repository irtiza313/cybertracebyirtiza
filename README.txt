CYBERTRACE SUBMISSION PACKAGE

Files: index.html, style.css, script.js

Run: Keep all three files in the same folder and open index.html in a modern browser. An internet connection is needed for Leaflet maps and the public lookup APIs.

Deploy: Upload all three files to the same static hosting folder (for example, Netlify Drop).

Notes: Workspace records are stored in this browser via localStorage; export a JSON backup before clearing browser data. IP geolocation is approximate. Use public lookup features only for lawful, authorized research.
